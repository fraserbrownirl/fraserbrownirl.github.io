startupplaybook is my internal growth runbook repo, not a shipped consumer app. It holds operational notes plus a synced Blotato API reference: publish posts, upload media, create and find AI videos, voice IDs, and OpenAPI slices.

I use it when I am wiring scheduled social and video workflows without re-reading the help center each time. The Lovable shell at the root is a placeholder; blotato-docs is what I actually open.

If you expected a public product landing, there is not one — this page exists so a portfolio link has something honest to unfurl.
