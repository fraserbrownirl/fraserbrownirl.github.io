Commissioning CMS

This monorepo rebuilds a Salesforce commissioning CMS for major infrastructure handover. The bet is per-seat economics and offline field scale do not belong on force.com forever.

A punchwalk fork owns field capture. A new CMS core owns the record. Captures post as punch items onto project-tree nodes over one API seam. The factory in this repo runs PRD → spec → tickets → implement with shared CI and GitHub issues as tracker.

North star: automate, simplify, and accelerate the final stages of major infrastructure projects. The core landing zone and capture leaf are still being defined to-spec; the PRD and factory wiring are the spine.
