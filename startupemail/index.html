startupemail is the sending layer for a startup-ideas email product. Supabase edge functions render React Email templates and send through a verified notify subdomain on startupideas.email.

A separate generate-card-image function builds shareable poster cards from startup records — category, hooks, and value props interpolated into an image prompt. Cards feed the emails strangers actually open.

The README in the repo is still a stub; the migrations and functions are the real spec. I have not wired a single public marketing URL to this repo yet — this GitHub Page is the LinkedIn-safe entry.
